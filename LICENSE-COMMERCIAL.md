# Licensing scope and commercial OEM option

This repository combines a preserved MIT research foundation with new files
explicitly marked `SPDX-License-Identifier: AGPL-3.0-only`. This is an open-source
research structure with a possible separately negotiated OEM licence, not a
completed commercial contract or a claim of exclusive ownership.

| Material | Applicable licence |
| --- | --- |
| Baseline `project_live` package relocated under WP2, original tests/docs and their modifications | Existing [MIT licence](LICENSE), including copyright/permission notice |
| New source files explicitly marked AGPL-3.0-only in WP1–WP4 | [GNU AGPL version 3](LICENSE-AGPLv3) |
| Unmarked original project files and new repository documentation/tooling | MIT, unless a file states otherwise |
| Third-party code, models, hardware designs and dependencies | Their own licences; not relicensed by this document |

AGPL is not a noncommercial or research-only licence: commercial use is possible
under its terms. A separate commercial agreement can offer different terms only
for material whose relevant rights holders authorize that grant. No named Swedish
company, contributor copyright assignment, automatic sublicense authority, pricing,
support commitment, indemnity or clinical warranty is established here.

Existing MIT grants remain available, including commercial reuse of those copies.
Adding an AGPL file cannot revoke them. Contributions retain their authorship and
the applicable file licence; an AGPL-only contribution does not automatically give
the maintainer authority to grant an OEM exception. Before offering an alternate
licence, establish rights, dependency/model compatibility and agreed commercial
terms with the relevant rights holders. See [contribution policy](CONTRIBUTING.md).

The full licence text is unmodified from
[GNU's AGPLv3 text](https://www.gnu.org/licenses/agpl-3.0.txt).
The [GNU licensing FAQ](https://www.gnu.org/licenses/gpl-faq.en.html) discusses
commercial distribution and permissions. This scope record adds no restrictions
to rights granted by an applicable open-source licence. No CERN-OHL designation
is applied to hardware solely because the older reference suggested it.
